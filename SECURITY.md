# Security Policy

## Supported versions

Security fixes are made available in the latest stable release of ISKONOMY. Please update to that release before reporting an issue if you can.

## Reporting a vulnerability

Open the repository’s Security tab, select Advisories, then choose Report a vulnerability. Please use this private report for security issues.

Include the affected ISKONOMY version, your operating system, the potential impact, and the steps needed to reproduce the issue. Redact EVE SSO tokens, credentials, and private wallet data from any logs or screenshots.

Please give the maintainer time to investigate and release a fix before sharing technical details publicly.
